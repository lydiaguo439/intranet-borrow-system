# 文件借阅管理系统

一个简单易用的内网文件借阅管理系统。

**核心功能：**
- 📝 **借阅记录** - 记录文件借出时间、借阅人、应还时间
- ↩️ **归还管理** - 标记文件归还，自动更新状态
- 🔄 **转交支持** - 文件可在人员间转交，自动重算应还时间
- 👨‍💼 **管理员后台** - 查看所有未归还文件、超期提醒、导出报表

**特点：** 完全离线运行 | 内网保密 | 无需复杂配置 | 手机扫码即用

### 步骤2：准备项目文件

1. **新建文件夹**
   - 在你的电脑上新建一个名为 `借阅系统` 的文件夹
   - 例如：`D:\借阅系统`

### 步骤3：首次运行

#### Windows用户（推荐）

1. **打开CMD窗口** - 进入 `借阅系统` 文件夹，按 `Shift + 右键` → 选择"在此处打开PowerShell窗口"

2. **安装依赖**（仅需第一次）
   ```bash
   python -m pip install -r requirements.txt
   ```

3. **启动系统** - 双击 `start.bat` 或运行 `python app.py`
   - 浏览器会自动打开系统页面

#### Mac/Linux用户

```bash
cd 借阅系统
python -m pip install -r requirements.txt
python app.py
```

然后打开浏览器访问：`http://[你的内网IP]:5000`（根据app.py中INTERNAL_IP配置）

⚠️ **重要提醒**：CMD窗口必须保持打开，系统才能正常运行（详见前置条件）

---

#### 常见问题排查

| 问题 | 症状 | 解决方案 |
|------|------|--------|
| **pip命令找不到** | `pip: 不是内部或外部命令` | 改用 `python -m pip install -r requirements.txt` |
| **Python找不到** | `python: 不是内部或外部命令` | 重新安装Python，勾选"Add Python to PATH" |
| **requirements安装失败** | 显示`ERROR`或`failed` | 检查网络，或运行 `python -m pip install --upgrade pip` 后重试 |
| **端口被占用** | `Address already in use` | 关闭占用5000端口的其他程序 |
| **无法访问系统** | 输入IP后无反应 | 检查CMD窗口是否开着，重启start.bat试试 |

## 📱 使用流程

### ⚡ 前置条件（使用前必读）

**使用系统之前，请确保：**

1. **管理电脑的CMD窗口必须保持打开**
   - 系统运行需要 `app.py` 持续执行
   - CMD窗口关闭 = 系统离线，所有人都无法访问
   - 如果不小心关闭了，重新运行 `start.bat` 即可恢复

2. **管理电脑必须在工作状态**
   - 不能关机或进入休眠
   - 不能断网或WiFi掉线
   - 不能被其他人关闭

3. **其他人才能借阅文件**
   - 只有管理电脑运行系统时，员工才能通过手机扫码或输入IP访问
   - 没有系统运行，再多的账号也用不了

**总结一句话：** 系统就像一个放在你电脑上的"借阅柜台"，必须你的电脑开着、系统运行着，别人才能来借还文件。

---

### 功能1：借出文件

1. **拿手机扫二维码** → 打开系统
2. **点击"借出"标签页**
3. **填写表单**：
   - **来文日期** *（必填）
   - **来文单位** *（必填，支持自动完成历史记录）
   - 文件名（可选）
   - 文号（可选）
   - **借阅人** *（必填）
   - **借阅类型** *（纸质/电子）
   - **借阅天数** *（必填）
   - 用途（可选）
4. **点击"确认借出"** → 记录已保存

**自动功能**：
- ✓ 计算应还时间 = 今天 + 借阅天数
- ✓ 记忆你最近用过的10个单位，下次输入时自动提示

---

### 功能2：归还和转交文件

#### 归还文件

1. **扫二维码** → 打开系统
2. **点击"归还"标签页**
3. **选择搜索方式**（三选一）：
   - **按单位搜索** - 输入来文单位，显示该单位所有未归还文件
   - **按文件名搜索** - 模糊搜索，输入几个字就能找到
   - **按借阅人搜索** - 显示某人借走的所有文件
4. **点击整行选择文件** → 显示完整信息
5. **点击"确认归还"** → 标记为已归还，自动更新返还时间

#### 转交给他人

当需要把已借出的文件转交给另一个人时：

1. **找到该文件**（同上，用搜索方式找到）
2. **点击"转交给他人"按钮**
3. **填写转交信息**：
   - **接收人姓名** *（必填）
   - **借阅天数** *（必填）- 输入新的借阅天数
4. **点击"确认转交"** → 系统自动：
   - 更新借阅人为新人名
   - 重新计算应还时间 = 今天 + 新的借阅天数
   - 更新转交记录

**转交注意事项**：
- 转交只改变"当前借阅人"，原始借出信息保留
- 支持多次转交（A转给B，B转给C）
- 借阅天数可以重新设置，不受原借阅天数限制

---

### 功能3：管理员视图

1. **点击"管理员"标签页**
2. **输入管理员密码**（默认：admin123）
3. **查看待归还清单**：
   - 🔴 **已超期（N天）** - 红色标记，超期天数最多的排最上面
   - 🟡 **即将超期（N天）** - 黄色标记，最快超期的排最上面
   - 🟢 **正常** - 绿色标记，按应还时间排序
4. **导出功能**：
   - 点击"📥 导出Excel"按钮
   - 生成待归还文件清单.xlsx，包含所有未归还文件的详细信息
   - 自动命名为：待归还文件清单_YYYYMMDD.xlsx

## ⚙️ 配置与常见问题

### 配置说明

**内网IP配置（重要）**

编辑 `app.py` 第18行，改成你的内网IP：

```python
INTERNAL_IP = 'xxx.xxx.xxx.xxx'  # 例如：192.168.1.50
```

获取方法：打开CMD输入 `ipconfig`，找 `IPv4 地址`

**管理员密码**

编辑 `templates/index.html` 搜索并修改：

```javascript
const ADMIN_PASSWORD = 'admin123';  // 改这里
```

### 常见问题

**Q1: 借阅单位下拉菜单怎么用自定义内容？**  
系统会记住你最近用过的10个单位。输入时自动显示建议，可点击选择或继续输入自定义。

**Q2: 转交时输入小数天数会怎样？**  
系统自动四舍五入。如0.2天会转为1天（最少保证1天）。

**Q3: 管理员导出的Excel文件在哪？**  
浏览器自动下载到下载文件夹，文件名为：`待归还文件清单_YYYYMMDD.xlsx`

**Q4: 系统关闭后数据会丢失吗？**  
不会。数据保存在 `借阅台账.xlsx`，关闭系统只是停止访问，数据永久保存。建议定期备份。

**Q5: 能多人同时使用吗？**  
可以。同一内网的任何设备都可以通过 `http://[电脑IP]:5000` 访问。
