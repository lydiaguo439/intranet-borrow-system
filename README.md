# 文件借阅管理系统 - 部署和使用指南

## 📋 系统概述

- **功能**: 文件借阅记录、多种搜索方式、状态追踪、管理员统计
- **特性**: 完全离线运行、内网保密、无需上云、自动计算超期
- **部署**: Windows/Mac本地运行
- **界面**: Web浏览器（手机/电脑都可以）

---

## 🚀 快速开始

### 步骤1：准备环境

1. **安装Python**（仅需一次）
   - 下载: https://www.python.org/downloads/
   - 安装时勾选"Add Python to PATH"
   - 验证: 打开CMD，输入 `python --version`

2. **确认文件位置**
   - 收文台账位置: `D:\收文归档\收文台账.xlsx`
   - 借阅台账位置: 同目录下自动生成 `借阅台账.xlsx`

---

### 步骤2：首次运行

#### Windows用户（推荐）

在 `借阅系统` 文件夹中，双击 **start.bat** 即可

- 自动安装依赖
- 自动启动Web服务
- 浏览器自动打开 http://[你的内网IP]:5000（根据app.py配置）
- **重要：app.py需要持续运行**，关闭CMD窗口后系统将无法访问

#### Mac/Linux用户

```bash
cd 借阅系统
python -m pip install -r requirements.txt
python app.py
```

然后打开浏览器访问: http://[你的内网IP]:5000（根据app.py中INTERNAL_IP配置）

**网络访问：** 同一局域网内的任何设备可用 `http://[你的内网IP]:5000` 访问

---

### 步骤3：生成二维码

1. 在 `借阅系统` 文件夹中
2. 双击 **generate_qrcode.py**（或在CMD运行）
3. CMD窗口会显示本机IP和二维码链接
4. 生成 `qrcode.png` 文件
5. 打印此二维码（推荐A6大小，约10cm×10cm）
6. 用胶带贴在办公桌显眼位置

**工作原理：** 二维码自动编码本机IP地址，手机扫码后通过局域网连接到你的电脑。

## 📱 使用流程

### 功能1：借出文件

1. **拿手机扫二维码** → 打开系统
2. **点击"借出"标签页**
3. **填写表单**：
   - **来文日期** *（必填）
   - **来文单位** *（必填，支持自动完成历史记录）
   - 文件名（可选）
   - 文号（可选）
   - **借阅人** *（必填）
   - **借阅类型** *（纸质/电子）
   - **借阅天数** *（必填）
   - 用途（可选）
4. **点击"确认借出"** → 记录已保存

**自动功能**：
- ✓ 计算应还时间 = 今天 + 借阅天数
- ✓ 记忆你最近用过的10个单位，下次输入时自动提示

---

### 功能2：归还文件

1. **扫二维码** → 打开系统
2. **点击"归还"标签页**
3. **选择搜索方式**（三选一）：
   - **按单位搜索** - 输入来文单位，显示该单位所有未归还文件
   - **按文件名搜索** - 模糊搜索，输入几个字就能找到
   - **按借阅人搜索** - 显示某人借走的所有文件
4. **点击整行选择文件** → 显示完整信息
5. **选择操作**：
   - **确认归还** - 标记为已归还
   - **转交给他人** - 输入接收人名字和天数，自动计算新的应还时间

---

### 功能3：管理员视图

1. **点击"管理员"标签页**
2. **输入管理员密码**（默认：admin123）
3. **查看待归还清单**：
   - 🔴 **已超期（N天）** - 红色标记，超期天数最多的排最上面
   - 🟡 **即将超期（N天）** - 黄色标记，最快超期的排最上面
   - 🟢 **正常** - 绿色标记，按应还时间排序
4. **导出功能**：
   - 点击"📥 导出Excel"按钮
   - 生成待归还文件清单.xlsx，包含所有未归还文件的详细信息
   - 自动命名为：待归还文件清单_YYYYMMDD.xlsx

## ⚙️ 配置说明

### 内网IP配置（重要）

编辑 `app.py` 第18行：

```python
INTERNAL_IP = 'xxx.xxx.xxx.xxx'  # 改成你的内网IP地址
```

**如何获取你的IP：**
1. 打开CMD，输入 `ipconfig`
2. 找 `IPv4 地址` 这一行（例如：192.168.1.50）
3. 把这个IP填入上面的 `xxx.xxx.xxx.xxx` 位置

### 改变收文台账路径

编辑 `app.py` 第22行：

```python
RECEIVE_DB_PATH = Path("D:/收文归档/收文台账.xlsx")  # 改这里
```

### 改变管理员密码

编辑 `templates/index.html` 搜索：

```javascript
const ADMIN_PASSWORD = 'admin123';  // 改这里
```

## 🔍 常见问题

### Q1: 借阅单位下拉菜单怎么用自定义内容？
**A**: 系统会记住你最近用过的10个单位。输入时会自动显示建议，点击选择或继续输入自定义内容都可以。

### Q2: 转交时输入小数天数会怎样？
**A**: 系统会自动四舍五入。比如输入0.2天会被自动转为1天（最少保证1天）。

### Q3: 同一份文件被多人借过，系统能区分吗？
**A**: 能。系统用"来文日期+来文单位+借阅人+文件名"来精准定位每条记录。

### Q4: 管理员导出的Excel文件在哪？
**A**: 浏览器会自动下载到你的下载文件夹，文件名为：待归还文件清单_YYYYMMDD.xlsx

### Q5: 超期提醒怎么实现的？
**A**: 
- **管理员视图** - 自动按优先级显示，超期文件用红色标记在最上面
- **个人视图** - 借阅人输入名字查询时，逾期文件用红色标记

### Q6: 能多人同时使用吗？
**A**: 可以。同一网络内的任何设备都可以通过 `http://[电脑IP]:5000` 访问。

### Q7: 关闭cmd窗口后还能用吗？
**A**: 不能。app.py需要持续运行才能提供服务。关闭cmd后系统无法访问。

**三个解决方案：**
- **方案1（简单）** - 用的时候才启动，用完关闭
- **方案2（推荐）** - 设置开机自启，让系统自动运行
- **方案3（专业）** - 配置为Windows服务，后台运行
